# RetroHDR Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Special K style SDR to HDR for Bloodborne in IFreemz's shadPS4 fork: Perceptual Boost in the present pass, scRGB swapchain, F1 controls, released from Robert's fork.

**Architecture:** A new `Vulkan::RetroHdr` module decides once, when the swapchain picks its format, whether the session runs scRGB (Windows HDR on, scRGB offered, setting on, no RenoDX), and afterwards feeds the present pass its per-frame parameters by polling `dlss.ini`. `post_process.frag` applies the curve; the ImGui overlay gets an scRGB shader; the F1 panel edits the settings.

**Tech Stack:** C++23, Vulkan-Hpp, GLSL (glslang, Vulkan 1.3), Dear ImGui, DXGI 1.6 + Win32 DisplayConfig, CMake, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-14-retro-hdr-design.md`

## Review Focus

1. Hand-edited or corrupt `dlss.ini` values (`retro_hdr_brightness=abc`, `nan`, `-5`, `retro_hdr_peak=50`): the renderer and the F1 panel must fall back to defaults and clamp, never send NaN or a negative scale to the shader. Pinned in Task 3 step 3 (`FiniteOr`, clamps in `Poll`) and Task 7 step 2 (`std::isfinite` guard).
2. Frame generation on while toggling: the HUD-less frame goes through `pp_pass.Render` with the same `pp_settings`, so both images must get identical RetroHDR parameters or FSR frame generation mixes two looks. Pinned in Task 5 step 4: parameters are filled before the first `Render` call and not changed before the HUD-less one.
3. Missing `dlss.ini` (fresh install, no upscaler, file not yet written): `Start` must see defaults (feature off) without logging an error, and the F1 panel's first `Set` creates the file. Pinned in Task 3 step 3 (`ReadSettings` on a missing file returns defaults).
4. Multi-monitor or window on a non-HDR display: state comes from the monitor that holds the window (`MonitorFromWindow`), not the primary display. Pinned in Task 3 step 3 (`QueryDisplay` matches `desc.Monitor`) and checked in the Task 9 smoke list.
5. User gamma slider at its extremes (0.1 and 2.0 in the F3 devtools): `gamma()` can leave [0, 1]; the stock code value is clamped before decoding so `pow` never sees a negative base. Pinned in Task 5 step 2 (`clamp(encoded, 0.0, 1.0)` in both RetroHDR branches).

```cpp
// SPDX-FileCopyrightText: Copyright 2026 Robert Bopko
// SPDX-License-Identifier: GPL-2.0-or-later
// written by Robert Bopko (github.com/zeroznet) with Boba Bott (Claude Opus 5.5)
#pragma once

#include <string_view>
#include "common/types.h"

// SDR to HDR the way Special K retrofits SDR games: Perceptual Boost on the finished frame in the
// present pass, shown through an scRGB swapchain. Settings live in dlss.ini next to the
// upscaler's.
namespace Vulkan::RetroHdr {

enum class State {
    Disabled,
    Active,
    RenoDx,
    NotWindows,
    DisplayUnknown,
    WindowsHdrOff,
    NoScRgbFormat,
};

// Decided once, when the swapchain picks its format.
struct Session {
    State state{State::Disabled};
    float windows_peak_nits{};
    float sdr_white_nits{203.0f};
};

// Swapchain construction: whether the swapchain should be scRGB for RetroHDR.
bool Start(void* native_window, bool scrgb_supported);
const Session& GetSession();
std::string_view Describe(State state);

constexpr u32 ModeNone = 0;
constexpr u32 ModeOff = 1;
constexpr u32 ModeOn = 2;

struct PassParams {
    u32 mode{ModeNone};
    float brightness{1.0f};
    float sdr_white{1.0f}; // Windows SDR white level / 80 nits
};

// Presenter thread, every frame: re-reads dlss.ini when it changed.
PassParams Poll();

constexpr float DefaultBrightness = 2.0f;
constexpr float MinBrightness = 0.30f;

float PeakNits(float override_nits);
// Brightness at which SDR white reaches `peak_nits`.
float MaxBrightness(float peak_nits);
// The boost's output for SDR linear `value` at brightness 1.0, in nits.
float BoostedNits(float value);

} // namespace Vulkan::RetroHdr
```

```cpp
// SPDX-FileCopyrightText: Copyright 2026 Robert Bopko
// SPDX-License-Identifier: GPL-2.0-or-later
// written by Robert Bopko (github.com/zeroznet) with Boba Bott (Claude Opus 5.5)
#include "video_core/renderer_vulkan/vk_retro_hdr.h"

#include <algorithm>
#include <chrono>
#include <cmath>
#include <cstdlib>
#include <filesystem>
#include <fstream>
#include <optional>
#include <string>

#include "common/logging/log.h"
#include "video_core/renderer_vulkan/vk_bb_temporal_dlss.h"
#include "video_core/renderer_vulkan/vk_hdr_mod.h"

#ifdef _WIN32
#define WIN32_LEAN_AND_MEAN
#define NOMINMAX
#include <vector>
#include <windows.h>
// After windows.h.
#include <dxgi1_6.h>
#endif

namespace Vulkan::RetroHdr {
namespace {

constexpr float MinPeakNits = 100.0f;
constexpr float FallbackPeakNits = 1000.0f;
constexpr float FallbackSdrWhiteNits = 203.0f;

// SMPTE ST 2084 as Special K's LinearToPQ and PQToLinear: `max_value` encodes to 1.0.
constexpr float PqM1 = 2610.0f / 16384.0f;
constexpr float PqM2 = 2523.0f / 4096.0f * 128.0f;
constexpr float PqC1 = 3424.0f / 4096.0f;
constexpr float PqC2 = 2413.0f / 4096.0f * 32.0f;
constexpr float PqC3 = 2392.0f / 4096.0f * 32.0f;

// Special K's SK_HDR_PQBoost_v1 (PerceptualBoost0..3 in widgets/hdr.cpp).
constexpr float BoostInputMax = 1.0f;
constexpr float BoostOutputMax = 0.1f;
constexpr float BoostGain = 1.273f;
constexpr float BoostDivisor = 0.5f;

float LinearToPq(float value, float max_value) {
    const float x = std::pow(std::max(value, 0.0f) / max_value, PqM1);
    return std::pow((PqC1 + PqC2 * x) / (1.0f + PqC3 * x), PqM2);
}

float PqToLinear(float code, float max_value) {
    const float x = std::pow(std::max(code, 0.0f), 1.0f / PqM2);
    return std::pow(std::max(x - PqC1, 0.0f) / (PqC2 - PqC3 * x), 1.0f / PqM1) * max_value;
}

struct Settings {
    bool enabled{};
    float brightness{DefaultBrightness};
    float peak_override{};
};

float FiniteOr(float value, float fallback) {
    return std::isfinite(value) ? value : fallback;
}

Settings ReadSettings() {
    Settings settings;
    std::ifstream file{BbDlssSettingsPath()};
    for (std::string line; std::getline(file, line);) {
        const auto eq = line.find('=');
        if (eq == std::string::npos)
            continue;
        const auto key = line.substr(0, eq);
        const auto value = line.substr(eq + 1);
        if (key == "retro_hdr")
            settings.enabled = std::atoi(value.c_str()) != 0;
        else if (key == "retro_hdr_brightness")
            settings.brightness = FiniteOr(float(std::atof(value.c_str())), DefaultBrightness);
        else if (key == "retro_hdr_peak")
            settings.peak_override = FiniteOr(float(std::atof(value.c_str())), 0.0f);
    }
    return settings;
}

Session session;
Settings polled;
std::filesystem::file_time_type polled_time{};
std::chrono::steady_clock::time_point next_poll{};

#ifdef _WIN32
struct Display {
    bool hdr_on;
    float peak_nits;
    float sdr_white_nits;
};

float SdrWhiteNits(HMONITOR monitor) {
    MONITORINFOEXW monitor_info{};
    monitor_info.cbSize = sizeof(monitor_info);
    UINT32 path_count{}, mode_count{};
    if (!GetMonitorInfoW(monitor, &monitor_info) ||
        GetDisplayConfigBufferSizes(QDC_ONLY_ACTIVE_PATHS, &path_count, &mode_count) !=
            ERROR_SUCCESS)
        return FallbackSdrWhiteNits;
    std::vector<DISPLAYCONFIG_PATH_INFO> paths(path_count);
    std::vector<DISPLAYCONFIG_MODE_INFO> modes(mode_count);
    if (QueryDisplayConfig(QDC_ONLY_ACTIVE_PATHS, &path_count, paths.data(), &mode_count,
                           modes.data(), nullptr) != ERROR_SUCCESS)
        return FallbackSdrWhiteNits;
    for (UINT32 i = 0; i < path_count; ++i) {
        const auto& path = paths[i];
        DISPLAYCONFIG_SOURCE_DEVICE_NAME source{};
        source.header.type = DISPLAYCONFIG_DEVICE_INFO_GET_SOURCE_NAME;
        source.header.size = sizeof(source);
        source.header.adapterId = path.sourceInfo.adapterId;
        source.header.id = path.sourceInfo.id;
        if (DisplayConfigGetDeviceInfo(&source.header) != ERROR_SUCCESS ||
            std::wstring_view{source.viewGdiDeviceName} != std::wstring_view{monitor_info.szDevice})
            continue;
        DISPLAYCONFIG_SDR_WHITE_LEVEL white{};
        white.header.type = DISPLAYCONFIG_DEVICE_INFO_GET_SDR_WHITE_LEVEL;
        white.header.size = sizeof(white);
        white.header.adapterId = path.targetInfo.adapterId;
        white.header.id = path.targetInfo.id;
        if (DisplayConfigGetDeviceInfo(&white.header) == ERROR_SUCCESS)
            return float(white.SDRWhiteLevel) / 1000.0f * 80.0f;
    }
    return FallbackSdrWhiteNits;
}

// The display that holds the window, which need not be the primary one.
std::optional<Display> QueryDisplay(HWND window) {
    const HMONITOR monitor = MonitorFromWindow(window, MONITOR_DEFAULTTONEAREST);
    IDXGIFactory1* factory{};
    if (!monitor ||
        FAILED(CreateDXGIFactory1(__uuidof(IDXGIFactory1), reinterpret_cast<void**>(&factory))))
        return std::nullopt;
    std::optional<Display> display;
    IDXGIAdapter1* adapter{};
    for (UINT a = 0; !display && factory->EnumAdapters1(a, &adapter) != DXGI_ERROR_NOT_FOUND; ++a) {
        IDXGIOutput* output{};
        for (UINT o = 0; !display && adapter->EnumOutputs(o, &output) != DXGI_ERROR_NOT_FOUND;
             ++o) {
            IDXGIOutput6* output6{};
            DXGI_OUTPUT_DESC1 desc{};
            if (SUCCEEDED(output->QueryInterface(__uuidof(IDXGIOutput6),
                                                 reinterpret_cast<void**>(&output6))) &&
                SUCCEEDED(output6->GetDesc1(&desc)) && desc.Monitor == monitor)
                display = Display{
                    .hdr_on = desc.ColorSpace == DXGI_COLOR_SPACE_RGB_FULL_G2084_NONE_P2020,
                    .peak_nits = desc.MaxLuminance,
                    .sdr_white_nits = SdrWhiteNits(monitor),
                };
            if (output6)
                output6->Release();
            output->Release();
        }
        adapter->Release();
    }
    factory->Release();
    return display;
}
#endif

State ResolveState([[maybe_unused]] void* native_window, [[maybe_unused]] bool scrgb_supported) {
    if (RenoDxLoaded())
        return State::RenoDx;
#ifdef _WIN32
    std::optional<Display> display;
    if (native_window)
        display = QueryDisplay(static_cast<HWND>(native_window));
    if (!display)
        return State::DisplayUnknown;
    session.windows_peak_nits = display->peak_nits;
    session.sdr_white_nits = display->sdr_white_nits;
    if (!display->hdr_on)
        return State::WindowsHdrOff;
    if (!scrgb_supported)
        return State::NoScRgbFormat;
    return polled.enabled ? State::Active : State::Disabled;
#else
    return State::NotWindows;
#endif
}

} // namespace

bool Start(void* native_window, bool scrgb_supported) {
    std::error_code error;
    polled_time = std::filesystem::last_write_time(BbDlssSettingsPath(), error);
    polled = ReadSettings();
    session.state = ResolveState(native_window, scrgb_supported);
    LOG_INFO(Render_Vulkan, "RetroHDR: {} (Windows peak {:.0f} nits, SDR white {:.0f} nits)",
             Describe(session.state), session.windows_peak_nits, session.sdr_white_nits);
    return session.state == State::Active;
}

const Session& GetSession() {
    return session;
}

std::string_view Describe(State state) {
    switch (state) {
    case State::Disabled:
        return "off";
    case State::Active:
        return "active";
    case State::RenoDx:
        return "RenoDX HDR is loaded";
    case State::NotWindows:
        return "needs Windows";
    case State::DisplayUnknown:
        return "Windows did not report this display";
    case State::WindowsHdrOff:
        return "turn on Use HDR in the Windows display settings, then restart the game";
    case State::NoScRgbFormat:
        return "the GPU driver offers no scRGB swapchain";
    }
    return {};
}

PassParams Poll() {
    if (session.state != State::Active)
        return {};
    const auto now = std::chrono::steady_clock::now();
    if (now >= next_poll) {
        next_poll = now + std::chrono::milliseconds{250};
        std::error_code error;
        const auto time = std::filesystem::last_write_time(BbDlssSettingsPath(), error);
        if (!error && time != polled_time) {
            polled_time = time;
            polled = ReadSettings();
        }
    }
    return {
        .mode = polled.enabled ? ModeOn : ModeOff,
        .brightness = std::clamp(polled.brightness, MinBrightness,
                                 MaxBrightness(PeakNits(polled.peak_override))),
        .sdr_white = session.sdr_white_nits / 80.0f,
    };
}

float PeakNits(float override_nits) {
    if (override_nits >= MinPeakNits)
        return override_nits;
    return session.windows_peak_nits >= MinPeakNits ? session.windows_peak_nits : FallbackPeakNits;
}

float MaxBrightness(float peak_nits) {
    return std::max(MinBrightness, peak_nits / BoostedNits(1.0f));
}

float BoostedNits(float value) {
    return PqToLinear(LinearToPq(value, BoostInputMax) * BoostGain, BoostOutputMax) / BoostDivisor *
           80.0f;
}

} // namespace Vulkan::RetroHdr
```

```glsl
// SPDX-FileCopyrightText: Copyright 2024 shadPS4 Emulator Project
// SPDX-License-Identifier: GPL-2.0-or-later

#version 450

layout (location = 0) in vec2 uv;
layout (location = 0) out vec4 color;

layout (binding = 0) uniform sampler2D texSampler;

layout (push_constant) uniform settings {
    float gamma;
    bool hdr;
    bool srgb_input;
    uint retro_mode;
    float retro_brightness;
    float retro_sdr_white;
} pp;

const uint RETRO_OFF = 1u, RETRO_ON = 2u;

const float cutoff = 0.0031308, a = 1.055, b = 0.055, d = 12.92;
vec3 gamma(vec3 rgb) {
    return mix(
        a * pow(rgb, vec3(1.0 / (2.4 + 1.0 - pp.gamma))) - b,
        d * rgb / pp.gamma,
        lessThan(rgb, vec3(cutoff))
    );
}

// Exact inverse of gamma() at unit gamma, for buffers that are sRGB encoded but must be sampled
// through a UNORM view because Vulkan has no sRGB variant of the 10-bit format.
vec3 degamma(vec3 rgb) {
    return mix(
        pow(max(rgb + b, 0.0) / a, vec3(2.4)),
        rgb / d,
        lessThan(rgb, vec3(d * cutoff))
    );
}

// SMPTE ST 2084 as Special K's LinearToPQ / PQToLinear: max_value encodes to 1.0.
const float pq_m1 = 2610.0 / 16384.0, pq_m2 = 2523.0 / 4096.0 * 128.0;
const float pq_c1 = 3424.0 / 4096.0, pq_c2 = 2413.0 / 4096.0 * 32.0, pq_c3 = 2392.0 / 4096.0 * 32.0;

vec4 linear_to_pq(vec4 v, float max_value) {
    vec4 x = pow(max(v, 0.0) / max_value, vec4(pq_m1));
    return pow((pq_c1 + pq_c2 * x) / (1.0 + pq_c3 * x), vec4(pq_m2));
}

vec4 pq_to_linear(vec4 code, float max_value) {
    vec4 x = pow(max(code, 0.0), vec4(1.0 / pq_m2));
    return pow(max(x - pq_c1, 0.0) / (pq_c2 - pq_c3 * x), vec4(1.0 / pq_m1)) * max_value;
}

// BT.709 primaries, D65, as Special K's Rec709_to_XYZ / XYZ_to_Rec709 (column-major).
const mat3 rec709_to_xyz = mat3(
    0.4123908, 0.2126390, 0.0193308,
    0.3575843, 0.7151687, 0.1191948,
    0.1804808, 0.0721923, 0.9505321);
const mat3 xyz_to_rec709 = mat3(
    3.2409699, -0.9692436, 0.0556301,
    -1.5373832, 1.8759675, -0.2039770,
    -0.4986108, 0.0415551, 1.0569715);

// Special K Perceptual Boost v1 with 33% Color Boost. SDR input keeps XYZ below 1.09, far from
// where the PQ inverse diverges (code 1.98).
vec3 perceptual_boost(vec3 rgb) {
    vec3 xyz = max(rec709_to_xyz * rgb, 0.0);
    if (xyz.y <= 0.0) {
        return vec3(0.0);
    }
    vec4 boosted = pq_to_linear(linear_to_pq(vec4(xyz, xyz.y), 1.0) * 1.273, 0.1) / 0.5;
    return xyz_to_rec709 * mix(xyz * boosted.w / xyz.y, boosted.xyz, 0.333);
}

void main() {
    vec4 color_linear = texture(texSampler, uv);
    if (pp.hdr) {
        color = color_linear;
    } else {
        if (pp.srgb_input) color_linear.rgb = degamma(color_linear.rgb);
        vec3 encoded = gamma(color_linear.rgb);
        if (pp.retro_mode == RETRO_ON) {
            vec3 sdr = pow(clamp(encoded, 0.0, 1.0), vec3(2.2));
            color = vec4(perceptual_boost(sdr) * pp.retro_brightness, color_linear.a);
        } else if (pp.retro_mode == RETRO_OFF) {
            color = vec4(degamma(clamp(encoded, 0.0, 1.0)) * pp.retro_sdr_white, color_linear.a);
        } else {
            color = vec4(encoded, color_linear.a);
        }
    }
}
```

````markdown
A fork of [IFreemz/shadPS4-Bloodborne-DLSS-FSR](https://github.com/IFreemz/shadPS4-Bloodborne-DLSS-FSR) `v1.9.0-pre.3` (threaded renderer, DLSS / FSR 4 upscaling, frame generation) that adds one thing: an SDR to HDR mode in the F1 panel. It expands the finished SDR frame with Special K's Perceptual Boost and shows it through an scRGB swapchain. Everything else is IFreemz's build, unchanged; see the [upstream README](https://github.com/IFreemz/shadPS4-Bloodborne-DLSS-FSR/blob/v1.9.0-pre.3/README.md) for upscaling, patches and frame generation.

## The problem

Bloodborne is an SDR game. The HDR mod for this build, RenoDX, swaps the game's shaders by matching the hash of the SPIR-V the emulator generates, and shadPS4 generates different SPIR-V on AMD than on NVIDIA, so the mod does not engage on AMD cards. Special K's HDR retrofit needs NVIDIA's DXGI interop for Vulkan games, and Windows AutoHDR and RenoDX's generic add-on cover DirectX only. On AMD there was no way to play it in HDR.

## How it works

```
 upscaler output ─► present pass ─────────────► frame (FP16) ─► game window ─► scRGB swapchain ─► Windows HDR
                    stock SDR code value                         F1 overlay at SDR desktop brightness
                    → gamma 2.2 decode
                    → Special K Perceptual Boost (PQ gain 1.273, Color Boost 0.333)
                    → × brightness
```

- Runs inside the existing present pass: no extra pass, no extra copy.
- The swapchain switches to scRGB (`R16G16B16A16_SFLOAT`, extended sRGB linear) at startup when the setting is on, Windows HDR is on for the display that holds the window, and the driver offers the format.
- Peak brightness comes from Windows (`MaxLuminance` of that display); the brightness slider stops where SDR white reaches it, so nothing clips.
- With the checkbox off, the same session shows the stock SDR image at the Windows SDR white level: an instant A/B, no restart.

## Install

1. Have IFreemz's [1.9.0-pre.3 release](https://github.com/IFreemz/shadPS4-Bloodborne-DLSS-FSR/releases/tag/v1.9.0-pre.3) set up (plus the FSR 4 add-on if you use it). Copy that folder.
2. Download the [latest RetroHDR release](https://github.com/zeroznet/shadPS4-Bloodborne-DLSS-FSR-RetroHDR/releases), check it (`sha256sum -c SHA256SUMS`), and put its `shadPS4.exe` into the copied folder.
3. Add the folder in your launcher (QtLauncher: Version Manager → Add Custom).
4. Delete `%APPDATA%\shadPS4\cache\CUSA03173` before the first run: a new exe is a new emulator version, and a mixed shader cache can hang startup.

## Usage

Turn on **Use HDR** in Windows display settings. In game press **F1**, section **SDR to HDR**:

| Control | What it does |
|---|---|
| SDR to HDR | First time: tick it and restart the game. After that it switches between HDR and the stock SDR look live. |
| HDR brightness | Special K's Brightness Scale. The line below shows where SDR white and 18 % gray land, in nits. |
| HDR peak | `auto` uses the value Windows reports for the display; set your own if the display reports none or a wrong one. |

Settings are saved in `dlss.ini` (`retro_hdr`, `retro_hdr_brightness`, `retro_hdr_peak`). A change to Windows HDR takes effect after a game restart. White HUD elements are expanded like the rest of the image, as with Special K.

To measure the output, start the emulator with `SHADPS4_HDR_METER=1`: a readout under the frame counter shows peak and median nits.

## Building

GitHub Actions builds every pull request and every push to `main` on `windows-2025-vs2026` (clang-cl + Ninja); the exe is attached to the run as `shadPS4-exe-only-win64-<hash>`. Tags `v1.9.0-pre.3-retrohdr.N` publish a release. Local Windows builds follow the upstream [Windows build guide](https://github.com/IFreemz/shadPS4-Bloodborne-DLSS-FSR/blob/v1.9.0-pre.3/documents/building-windows.md).
````

- [ ] **Step 4: Release job at the end of `build.yml`**

Append after the last line of the `windows-sdl` job (after its `Upload Windows SDL artifact` step), keeping two-space job indentation:

```yaml

  release:
    if: startsWith(github.ref, 'refs/tags/v')
    needs: [get-info, windows-sdl]
    runs-on: ubuntu-24.04
    permissions:
      contents: write
    steps:
    - uses: actions/checkout@v7
    - uses: actions/download-artifact@v8
      with:
        name: shadPS4-exe-only-win64-${{ needs.get-info.outputs.shorthash }}
        path: dist
    - name: Package
      run: |
        cd dist
        zip -9 "shadPS4-RetroHDR-${GITHUB_REF_NAME}-win64.zip" shadPS4.exe
        sha256sum "shadPS4-RetroHDR-${GITHUB_REF_NAME}-win64.zip" > SHA256SUMS
    - name: Create GitHub release
      env:
        GH_TOKEN: ${{ github.token }}
      run: |
        gh release create "${GITHUB_REF_NAME}" dist/*.zip dist/SHA256SUMS \
          --repo "${GITHUB_REPOSITORY}" --title "${GITHUB_REF_NAME}" \
          --notes-file .github/release-notes.md --prerelease
```
